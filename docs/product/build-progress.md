The app declared both `NSAllowsArbitraryLoads` and `NSAllowsLocalNetworking`; the latter overrides the broad HTTP allowance. Removing the conflicting key restores HTTP support for user-entered provider addresses. See [Apple's ATS key precedence](https://developer.apple.com/documentation/bundleresources/information-property-list/nsapptransportsecurity/nsallowsarbitraryloads). Transport-policy failures now receive a specific message without exposing credential-bearing URLs.

Downloads allow up to 256 MiB with progress-based cancellation, parsing caps program/field sizes, and each parser reuses its own date formatter. Playlist/API response limits remain unchanged.
