# Player Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Playback gets its own full-screen screen, opened with the native zoom transition from the tapped item, minimized by swiping down into the mini player, and full screen in landscape.

**Architecture:** The player becomes a `fullScreenCover` with `.navigationTransition(.zoom(sourceID:in:))`. Tapped items mark themselves with `.matchedTransitionSource` through a shared namespace in the environment. The screen shows only the native `AVPlayerViewController` (AirPlay, PiP, audio/subtitle menus) plus title, channel/league, live progress, previous/play-pause/next and a favorite heart. `PlaybackController` is unchanged.

**Spec:** `docs/superpowers/specs/2026-11-08-app-redesign-design.md`, sub-project 3 "Player".

## Global Constraints

- Same build, test and simulator commands as `2026-11-08-home.md`.
- Keep `PlaybackController` behaviors: first-frame readiness, bounded reconnect, automatic alternate feeds on failure.
- Portrait player contents, exactly: video, title, channel (and league for games), live progress for the current guide program, previous / play-pause / next, favorite heart. AirPlay, PiP and audio/subtitle menus come from the native player controls.
- Removed from the player: stream picker, quality picker, Change Channel, Channel Details, recording, explanatory footnotes. Game stream choice stays on the game page.
- Previous/next (decision): step through favorites when the playing channel is a favorite, otherwise through the lineup, wrapping at the ends.

## Review Focus

1. **Playing channel not in the list** (opened from Search or a game feed): next/previous start from the first channel of the list instead of doing nothing. (Task 1)
2. **Rotation while a sheet or menu is open**: landscape shows only the video, and rotating back restores the controls. (Task 3)
3. **Swipe down during connection**: playback continues and the mini player shows "Connecting". (Task 3)
4. **Source item scrolled off or gone** (zoom source missing): presentation falls back to the default transition without a crash. (Task 2)
5. **Favorite toggled from the player**: the heart and Home's Your Channels update immediately. (Task 3)

### Task 1: Channel stepping

**Files:** Create `mySportly/Core/ChannelStepping.swift`; Test `CoreTests/ChannelSteppingTests.swift`; Modify `mySportly/App/AppStore.swift`.

**Interfaces:**
- `public enum ChannelStepping { public static func neighbor(of id: String?, in ids: [String], offset: Int) -> String? }`: wraps at both ends; returns `ids.first` (offset > 0) or `ids.last` (offset < 0) when `id` is not in `ids`; `nil` for an empty list.
- `AppStore.stepChannel(by offset: Int)`: uses favorites' IDs when the playing channel is a favorite, else `lineup` IDs; plays the neighbor.
