# Search Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Search that feels instant and uncluttered: recent searches and browse tiles before typing; instant local results grouped as Teams, Live now and Channels while typing.

**Architecture:** A pure `SearchGrouping.group` in `SportlyCore` turns the existing `CatalogQueryIndex.search` matches plus the sports directory's team choices into the three groups, ranked by follows and lineup order. `RecentSearches` keeps the last 8 queries in personal data. `SearchScreen` is rewritten around those; browse tiles open a category list, a league page or a sport query. The AI fallback slot is left for sub-project 6.

**Spec:** `docs/superpowers/specs/2026-11-08-app-redesign-design.md`, sub-project 5.

## Global Constraints

- Same build, test and simulator commands as `2026-11-08-home.md`.
- Removed: "Try a Search", the lineup filter and scope controls in Search, status text, "Ask Apple Intelligence", "Show More" copy beyond a single button.
- Before typing: **Recent** (up to 8, with Clear) and **Browse** tiles: Sports, News, Movies, Kids, one tile per added league, then Basketball, Football, Soccer, Baseball, Hockey.
- While typing: **Teams**, **Live Now**, **Channels**; empty groups hidden; results update as you type with no extra button. The search always uses the preferred lineup (My Lineup).
- No network or model call in this sub-project.

## Review Focus

1. **Typing before the full catalog is ready**: results come from the launch snapshot (existing `snapshotMatches`), grouped the same way. (Task 2)
2. **A query that is only a team nickname** ("knicks"): Teams shows New York Knicks first even without a live game. (Task 1)
3. **A channel matched by name that is also live** appears once, under Live Now. (Task 1)
4. **Very short queries** (one character): no team flood; teams need 2+ characters. (Task 1)
5. **Recent searches with different case** ("NBA", "nba") are stored once, newest first. (Task 1)

### Task 1: Core grouping and recents
**Files:** Create `mySportly/Core/SearchGrouping.swift`; Test `CoreTests/SearchGroupingTests.swift`.
- `public struct SearchGroups: Sendable { public var teams: [SportsLibraryItem]; public var liveNow: [CatalogMatch]; public var channels: [CatalogMatch] }`
- `public enum SearchGrouping { public static func group(query: String, matches: [CatalogMatch], choices: [SportsFollowChoice], followedIDs: Set<String>, at date: Date) -> SearchGroups }`: teams match name or alias case/diacritic-insensitively (queries under 2 characters match no teams), followed first, then name, at most 8; a match with a program live at `date` goes to Live Now, the rest to Channels, each keeping index order.
- `public enum RecentSearches { public static let limit = 8; public static func adding(_ query: String, to list: [String]) -> [String] }`: trims, drops empties, dedupes case-insensitively keeping the newest first, caps at 8.
